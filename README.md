# Physics-Informed Inference of Ideological Distribution Dynamics in U.S. Legislatures

This repository contains the paper source, figures, and project page for a study of ideological distribution dynamics in U.S. legislatures. The method learns a nonlinear, nonlocal Fokker–Planck model from Voteview and Shor–McCarty ideology data.
